## 📖 Proje Hakkında

**Polytalk**, modern yapay zeka teknolojilerini kullanarak dil öğrenmeyi eğlenceli ve etkili hale getiren kapsamlı bir platformdur. Google Gemini AI entegrasyonu ile kullanıcılar gerçek zamanlı konuşma pratiği yapabilir, kişiselleştirilmiş kelime kartları oluşturabilir ve detaylı performans analizleri alabilirler.

### 🎯 Ana Hedefler
- **Kişiselleştirilmiş Öğrenme Deneyimi**: Her kullanıcının seviyesine ve öğrenme hızına uygun içerik
- **AI Destekli İnteraktif Öğrenme**: Yapay zeka ile gerçek zamanlı konuşma pratiği
- **Gamification**: XP sistemi, seviye atlama ve streak takibi ile motivasyon
- **Kapsamlı Analiz**: Detaylı performans raporları ve görselleştirmeler

## 🚀 Kurulum

### 📋 Gereksinimler

- **Python**: 3.8 veya üzeri
- **pip**: Python paket yöneticisi
- **Git**: Versiyon kontrol sistemi
- **Tarayıcı**: Modern web tarayıcısı (Chrome, Firefox, Safari, Edge)

### 🔧 Adım Adım Kurulum

#### 1️⃣ **Projeyi Klonlayın**
```bash
# GitHub'dan projeyi indirin
git clone https://github.com/your-username/polytalk.git

# Proje dizinine geçin
cd polytalk
```

#### 2️⃣ **Sanal Ortam Oluşturun**
```bash
# Python sanal ortamı oluşturun
python -m venv venv

# Sanal ortamı aktifleştirin
# Windows için:
venv\Scripts\activate

# Linux/Mac için:
source venv/bin/activate
```

#### 3️⃣ **Bağımlılıkları Yükleyin**
```bash
# Gerekli paketleri yükleyin
pip install -r requirements.txt

# Yükleme durumunu kontrol edin
pip list
```

#### 4️⃣ **Veritabanını Oluşturun**
```bash
# Veritabanını başlatın
python create_db.py

# Veritabanı dosyasının oluştuğunu kontrol edin
ls instance/
```

#### 5️⃣ **Konfigürasyon Yapın**
```bash
# .env dosyası oluşturun
touch .env

# Gerekli değişkenleri ekleyin
echo "SECRET_KEY=your-secret-key-here" >> .env
echo "GEMINI_API_KEY=your-gemini-api-key" >> .env
echo "FLASK_ENV=development" >> .env
```

#### 6️⃣ **Uygulamayı Başlatın**
```bash
# Flask uygulamasını çalıştırın
python app.py

# Veya Flask development server ile
flask run
```

#### 7️⃣ **Tarayıcıda Açın**
```
http://localhost:5000
```

### 🔧 Gelişmiş Konfigürasyon

#### Ortam Değişkenleri
```env
# .env dosyası
SECRET_KEY=your-super-secret-key-here
GEMINI_API_KEY=your-gemini-api-key-from-google
FLASK_ENV=development
FLASK_DEBUG=True
DATABASE_URL=sqlite:///instance/polytalk.db
```

#### Veritabanı Konfigürasyonu
```python
# config.py
class Config:
    SECRET_KEY = os.environ.get('SECRET_KEY') or 'dev-secret-key'
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL') or \
        'sqlite:///instance/polytalk.db'
    SQLALCHEMY_TRACK_MODIFICATIONS = False
```
